**Before-MX note (added 2026-10-20).** The bounce's "Original Message Details" give the created date as `10/13/2026 9:08:05 PM`. Office 365 bounce reports give that time in UTC. It also fits the order of events: Namecheap rejected the message, so it must have been sent while Namecheap's MX records were still published, before 21:35 UTC. The error details, copied from the bounce with my sender address left out:

```
Subject:              Test 00: before setup
Error:                550 5.7.367 Remote server returned not permitted to relay ->
                      554 5.7.1 <zetian@zetiantao.me>: Relay access denied
Message rejected by:  asp-relay.et.namecheap.tech
Sent by:              CO1PR03MB5666.namprd03.prod.outlook.com
```

When it was sent, the zone had no Zoho records. Its only mail records were Namecheap's email-forwarding MX servers (`eforward1`–`5.registrar-servers.com`, saved in [dns-before-zoho.md](dns-before-zoho.md)), with no forwarding rule set up for `zetian@`. Office 365 delivered the message to Namecheap's mail relay, and the relay refused it (`554 5.7.1 Relay access denied`) because it had no rule saying where to forward `zetian@`. The bounce confirms that a Namecheap server did the rejecting. That it rejected the message *because* no forwarding rule existed is my inference. Once Zoho's MX records were published, the same kind of message arrived (Test01 above).

## 2. Authentication (outside mailbox, outgoing message)

From "Ex06 Test03: Outbound" (sent Oct 17, 12:13 PT from zetiantao.me), as received by the outside mailbox (Microsoft 365):

```
Authentication-Results: mx.microsoft.com 1; spf=pass (sender IP is
 165.173.180.52) smtp.mailfrom=zetiantao.me; dkim=pass (signature was
 verified) header.d=zetiantao.me;dmarc=pass action=none
 header.from=zetiantao.me;compauth=pass reason=100
```

- SPF: pass. zetiantao.me's SPF record allows Zoho's sending server (sender6-of-o52.zoho.com, 165.173.180.52).
- DKIM: pass. The zetiantao.me signature (selector `zmail`) verified, so the signed headers and body arrived unchanged.
- DMARC: pass. The From domain (zetiantao.me) aligns with the domains that passed SPF and DKIM; no action taken.
